## 1. 统计方法

1. 用 `ttf-parser` 读取字体的 `cmap` 表；
2. **只取 Unicode 子表**（跳过 symbol / Mac-Roman 子表，否则会把编码当码位算）；
3. 汇总所有子表的码位，**排序去重**，得到该字体真正映射的字符集合；
4. 与 Unicode 区块表求交，得出各区块覆盖数；
5. `汉字数` = 下列区块覆盖数之和：

| 区块 | 码位范围 |
|---|---|
| 中日韩统一表意文字（基本区） | U+4E00–U+9FFF |
| 扩展 A | U+3400–U+4DBF |
| 扩展 B | U+20000–U+2A6DF |
| 扩展 C | U+2A700–U+2B73F |
| 扩展 D | U+2B740–U+2B81F |
| 扩展 E | U+2B820–U+2CEAF |
| 扩展 F | U+2CEB0–U+2EBEF |
| 扩展 I | U+2EBF0–U+2EE5F |
| 扩展 G | U+30000–U+3134F |
| 扩展 H | U+31350–U+323AF |
| 兼容表意文字 + 补充 | U+F900–U+FAFF、U+2F800–U+2FA1F |

TTC/OTC 集合字体会把各 face 的计数**相加**，区块表取字符最多的那个 face。

## 7. 数据落在哪、怎么用

统计结果除了这份报告，也写进了应用的索引库：

- 数据库：`%APPDATA%\ZFontManager\cache.db`
- 表：`file_cjk(path, size, mtime, stats)`
  - `stats` 是 JSON，字段含 `han` / `hanBasic` / `hanExtA` / `hanExtB` / `hanCompat` / `totalChars` / `kana` / `hangul` / `latin` / `fullwidth` / `blocks[]`
- 生成时机：每次扫描后在后台线程补齐，每次最多补 600 个文件，不阻塞首屏
- 日志：`%APPDATA%\ZFontManager\scan.log` 会记 `cjk=N fonts counted`

**自己重新生成报告**：

```bat
cd app\src-tauri
cargo run --release --bin cjk_report -- --format md > ..\..\reports\cjk.md
cargo run --release --bin cjk_report -- --format tsv > ..\..\reports\cjk.tsv
```

也可以只统计某个目录：

```bat
cargo run --release --bin cjk_report -- --format md "D:\字体库"
```
