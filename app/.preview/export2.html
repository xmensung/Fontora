项目字体包

把字体文件、fonts.css、manifest.json 和一份授权说明打成一个 zip，解压就能丢进项目目录。

WOFF2 只对 TrueType 轮廓可靠；整份中文字体要几秒到十几秒，一次最多 200 个字重。

@font-face 片段

路径按包内目录写（fonts/… 或 web/…）。单独复制到别的项目时，记得改成实际的字体位置。

/* ZFontManager · @font-face · 2026-10-20 09:31:02 */
/* 路径相对于本文件所在目录；字号字重可直接用数值选择。 */

/* 思源宋体 */
@font-face {
  font-family: "思源宋体";
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url("fonts/思源宋体.ttf") format("ttf");
}
