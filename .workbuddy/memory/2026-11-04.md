## 第三轮修正：拆掉假家族 + 洗净脏名字

**用户指出两处敷衍**：`字体包/` 里出现「7款免费可商用自然磨损质感模拟油墨字体」「32款艺术手写英文字体」

**判定标准（写死在脚本里）**：包名是厂商/产品名 → 可作包存在；是营销文案（N款/合集/套装/字体包/组合/简洁）
→ 不是家族，拆散归位。用户选「拆散归位」。

**执行结果**
- 10 个合集 1,223 个字体拆散：西文/手写手迹 711（手写英文字体包 513、32款 125、68款 70…）、
  西文/展示装饰/其他装饰 367、中文/黑体 71（汉仪旗黑系列）、其余零星。
  判书体：先看字体自己的族名（EN_KIND/CN_BOOK），判不出用**包名提示**兜底（PKG_HINT）。

- 包名清洗 18 处（去 `_猫啃网`、版本号、`(完整版)`、营销词），文件名/附件名 76 处。

**踩的坑**
1. `import plan_reorg` 会把整个脚本跑一遍（它是脚本不是模块），产生一堆无关输出；要用的话得先拆成 lib。
2. 改名同步清单要**循环替换**：文件先改名、父目录后改名时，路径要连续替换两次，

4. `os.path.exists()` 在 Windows 大小写不敏感，`segoe → Segoe` 会命中「目标已存在」分支被跳过，

## 第四轮：IBM Plex 四包合一（21:20）

**背景**：用户批准合并 `字体包/` 下并列的 `IBM Plex` / `IBM Plex Mono` / `IBM Plex Sans` / `IBM Plex Sans SC`。

**关键发现**：863 个字体二进制字节级重复 0 个——四个包不是重复，是同一家族的互补构建：
- 全集（1,099 文件）缺 base Sans（0 个），Mono 是 v2.004（1,123 字形）
- Mono 子包是 v2.005（1,205 字形，多 82），且只有它有 Mono 的 ttf
- Sans 子包是 base Sans 唯一来源；Sans SC 子包是简体中文唯一来源（29,562 字形）

**做法**：按 name 表 (family, subfamily, italic, ext) 做字面级去重，版本高者胜；
`字体/` 下按 14 个子家族分目录；`网页字体/` 放 519 个 woff2/eot；
`网页开发包/` 收敛成 14 个 ibm-plex-* 官方包树（子包的 css 覆盖全集的旧版，unicode-range 更细）；
`说明/` 放唯一一份 LICENSE + 授权说明 + 预览图。

**结果**：1,553 → 1,266 文件，631.2 → 381.9 MB，字体 865 → 793。
删除 287：16 旧版 Mono、56 个 -unhinted（247 MB，占体积减少的 99%）、107 份重复授权、109 份重复样式表。

**踩的坑（重要）**
1. **Bash 里 `python -c "..."` 传 Windows 路径会被转义吃掉反斜杠**（`r'G:/Mine/...'` 变成 `G:/Mine/...`），
   导致 `os.path.join` 拼出的键和 JSON 里的 `from` 对不上，remap 静默返回 0 条。
   修法：写成 `.py` 文件跑，或两侧都过 `os.path.normcase(os.path.normpath())`。
2. 清单里 `old` 相对 `素材类`、`new` 相对 `字库`，两个基准不同，前缀判断少一层会全盘错。
3. 前缀过滤 `startswith('字体包/IBM Plex/')` 会漏掉 `字体包/IBM Plex Mono/` 这类兄弟目录（313 行没改到）。
4. 非字体同名同内容**不能盲删**：`ibm-plex-math-all.css` 与 `-default.css` 内容相同但文件名不同，
   删了会让官方包的 `@import` 链 404。只对 license 类做去重。
