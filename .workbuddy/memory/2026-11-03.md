## 20:30 缺口详解（逐行核过代码后的修正）

产出 `docs/Fontora-功能缺口详解.md`，11 项缺口 + 次要缺口表 + 依赖关系。
核对代码后修正了前一版几处不够准的说法：

- **`get_charset` 不能用来判缺字**：`lib.rs:698` 末尾 `cps.truncate(4096)`，
  中文字库 2~7 万码点会被截断，拿去判缺字会大面积误报。应按文本逐字
  `face.glyph_index(ch)` 判定；且 `Some(GlyphId(0))`（.notdef）也算缺。
  判字符集标准要用 `cjk::face_codepoints`（无截断）。
- **字号不是缺的**：`SIZES = [8,14,18,24,32,48,64,96]` 已有滑杆（`TopBar.tsx:514`），
  详情页另有 70~160% 缩放。真正缺的是**行高**（全无）与连续 px。
- **体检已有字库级缺字**：`health.rs:174 missing_common` 用 3500 常用字表，
  `health.rs:452` 报"缺 N 字"。缺的是**预览文本级**判定与标红/筛选。
- **OpenType 特性不用自己解析 GSUB**：`get_features` 已有数据，前端用
  `font-feature-settings` 让 WebView2 渲染开/关对比即可，ttf-parser 本来也不给替换规则。
- 中文书体筛选零成本：`tagTaxonomy`（书体源流 13 值）+ `tagSuggest` 正则都已存在。

**结论一句话**：11 项里有 4 项（缺字/书体/OpenType/字符集标准）属于"数据已在、只缺出口"，
和 0.9.0「功能做完没打包」是同一个毛病——完成度按"代码能跑"算，不按"用户看得见"算。

## 21:05 打包事故：release 被编成 dev 模式，双击「localhost 拒绝连接」

commit `fbbd5a9`。发布 0.10.1（24,325,632 B，sha256 bab4b6dd…c11a1b，
zip 9,021,026 B，testzip=None）。0.9.0 与 0.10.0 两个包已下架（同一毛病）。

**根因（务必记住）**
Tauri 2 判断 dev/prod 只看 `custom-protocol` feature，与 `--release` 无关。
`tauri-2.12.3/build.rs`：
  `let custom_protocol = has_feature("custom-protocol"); let dev = !custom_protocol;`
  → `cargo:dev={dev}`；`tauri-build::is_dev()` 读 `DEP_TAURI_DEV` 后设 `cfg(dev)`。
不带该 feature 编出来的 exe：前端资源不嵌入（Assets 为空）+ 二进制带 dev 标记
→ 运行时加载 `devUrl`(localhost:1420) → 双击就是 Edge 的 ERR_CONNECTION_REFUSED。
窗口配的是 `visible:false`，前端没跑起来就不会 show，所以坏包表现为「一张错误页」。

**证据链（以后查同类问题照这个顺序）**
1. `target/release/build/fontora-*/output` 里搜 `cargo:rustc-cfg=dev` —— 有就是 dev 包。
   三次构建：10-31 17:58 无（所以 0.8.1 能跑）、11-03 19:46 与 20:47 都有（0.9.0 / 0.10.0 皆坏）。
2. 用 `dist/index.html` 里的前端指纹去 grep exe —— 好包有 `index-2eCH2PkD.js`，坏包 0 条。
3. 体积：坏包 ~23.4 MB，好包 ~24.3 MB，差的 841 KB 就是内嵌前端。

**修法（三重）**
- `Cargo.toml` 加 `[features] custom-protocol = ["tauri/custom-protocol"]`；
- `build.rs` 守卫：`PROFILE=release` 且无 `CARGO_FEATURE_CUSTOM_PROTOCOL` 就 panic
  （已验证：`cargo check --release` 在 build.rs:12 停住）；
- `package.json` 加 `build:exe` 脚本，一条命令走完前端 + 生产模式编译。

**推翻上一条说法**
上一段写的「pnpm build 之后必须 touch src-tauri/src/lib.rs」是误判：把 dev 包当成了
增量缓存问题。真实原因是 feature 缺失，跟 touch 无关，那条作废。

**实机验证可行（不必只靠静态检查）**
后台起 exe，查进程 Responding / MainWindowHandle / MainWindowTitle：句柄非 0 且标题为
Fontora，即说明前端已加载（`visible:false` 必须由前端 JS 调 show）。截屏方案被安全策略拦，
进程与窗口指标足够。
