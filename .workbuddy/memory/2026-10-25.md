     `.app-frame::before` 紫蓝光晕透明度 0.42。
3. 版本升 0.8.1 + 保留旧包：package.json / tauri.conf.json / Cargo.toml /

## 19:08 发布目录改版：exe 带版本号 + 每版一个 README

用户三点反馈：dist-portable 下 exe 与 zip 的区别没说清；**exe 文件名没带版本号**；
每个版本要有 GitHub 那种 README。改法：

发布目录定型为「一版一文件夹 + 同名 zip 并列」：
```
dist-portable/
├── README.md                        索引（版本表 / exe-vs-zip / 校验 hash）
├── Fontora-0.8.1/  Fontora-0.8.1.exe + README.md + CHANGELOG-详细.txt
├── Fontora-portable-0.8.1.zip       同内容（exe + README.md + CHANGELOG-详细.txt）
├── Fontora-0.8.0/  Fontora-0.8.0.exe + ...
├── Fontora-portable-0.8.0.zip
├── ZFontManager-0.7.2/  ZFontManager-0.7.2.exe + ...
└── ZFontManager-portable-0.7.2.zip
```
- **exe 一律带版本号**：`Fontora-0.8.1.exe` / `Fontora-0.8.0.exe` /
  `ZFontManager-0.7.2.exe`（0.7.2 原名 zfontmanager.exe，从 zip 里取出后改名）。
  改 exe 名安全：`store.rs::app_data_dir()` 取 `current_exe().parent()/Data`，与文件名无关。
- 原 README.txt（46 KB、逐版 P1~0.8.1）改名为 `CHANGELOG-详细.txt` 留档；
  0.8.0 / 0.7.2 的原说明从各自旧 zip 里取出，同样存为 `CHANGELOG-详细.txt`。
- 新写 4 个 README.md：总索引 + 三版各自（徽章 / 快速开始 / 功能 / 本版更新 /
  文件清单含 hash / 系统要求 / 数据位置 / FAQ / 已知限制 / 许可）。
  0.8.0 与 0.7.2 的 README 标注「旧版、已被 0.8.1 取代」并互相链接。
- 三个 zip 全部重打（exe + README.md + CHANGELOG），`testzip()` 均 None：
  0.8.1 8,986,199 B / 0.8.0 8,989,105 B / 0.7.2 9,016,340 B。
- 目录总计 96 MB（三份解压 exe 72 MB + 三包 26 MB）。若嫌大，可只留最新解压版，
  旧版仅留 zip。

**约定（后续发版沿用）**：产物命名 `Fontora-<版本>.exe` + `Fontora-portable-<版本>.zip`，
文件夹 `Fontora-<版本>/`，里面必须有 README.md 与 CHANGELOG-详细.txt。
